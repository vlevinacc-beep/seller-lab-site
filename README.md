# SELLER LAB — сайт

Многостраничный статический сайт лаборатории решений для селлеров SELLER LAB. Собран на чистом HTML/CSS/JS — без сборки и зависимостей, готов к загрузке на обычный хостинг (в т.ч. reg.ru).

## Структура

```
index.html          Главная
about.html           О проекте и команде
consulting.html      Консультации (15 000 ₽) + форма заявки
coaching.html        Коучинг «Выход есть» (45 000 ₽ / 3 сессии) + форма заявки
pro.html             SELLER LAB PRO (499 ₽/мес)
wildberries.html     Площадка: Wildberries
uzum.html            Площадка: Uzum Market
mercadolibre.html    Площадка: Mercado Libre
cases.html           Разборы и статьи
faq.html             FAQ
contacts.html        Контакты + форма обратной связи
privacy.html         Политика обработки данных

assets/css/style.css Стили (палитра «Карбон и паприка», Manrope + IBM Plex Mono)
assets/js/main.js    Мобильное меню и обработка форм заявок
assets/img/          Изображения (логотип, фото команды)
```

## Что нужно доделать перед запуском

1. **Логотип.** `assets/img/logo-mark.svg` реконструирован вручную по PDF-гайду брендбука (кольцо-квадрат, кольцо-круг, заливной треугольник — цвета и пропорции по паспорту логотипа). Это не оригинальные векторные файлы из логопака. Когда будет доступен архив `01_MASTER_VECTOR`, замените этот SVG на исходный и обновите инлайн-копии в `<header>`/`<footer>` каждой страницы.
2. **Приём заявок.** Формы (`data-lead-form` в `assets/js/main.js`) сейчас формируют письмо через `mailto:` — это временное решение до подключения оплаты и приёма заявок (онлайн-касса, сплит с Долями/Podeli — согласно брифу, после договора с агрегатором). Замените адрес `hello@sellerlab.io` на рабочий и/или подключите реальный backend (email-сервис, Telegram-бот, Google Sheets).
3. **Контактный email** на странице `contacts.html` — заглушка `hello@sellerlab.io`, нужно заменить на рабочий адрес.
4. **Политика обработки данных** (`privacy.html`) — черновик, нужно заполнить юридическими реквизитами оператора и датой публикации.
5. **Telegram** — в шапке и футере предусмотрено место под ссылку, добавьте её, когда канал появится.

## Деплой на reg.ru

Сайт полностью статический — загрузите содержимое репозитория (кроме `.git`, `README.md` можно оставить) в корень домена через файловый менеджер хостинга или по FTP/SFTP. Сборка не требуется.
